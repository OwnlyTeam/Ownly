Safety

Nothing happens behind your back.

Any single change can be found, understood, and taken back.

FIRST RUN

It reads you the terms

A full disclaimer you scroll through and accept before the app opens. Anything you do is on you — and it says so, in plain language.

EVERY CHANGE

Lands in the Changes list

User-level settings apply instantly. Machine-level ones ask for a Windows permission prompt. Both get a one-click Restore.

ALWAYS

The Activity log shows the command

Every action — and every undo — is written down with the exact registry write or command, and whether it needed admin.

Before you install

The honest bits.

Works on
Windows 10 (build 1809+) and Windows 11, 64-bit (x64). Not ARM or 32-bit.
Install
None. A single Ownly.exe — put it anywhere and double-click. Delete the file to remove it.
Size
About 470 MB. Large because it bundles its own copy of everything it needs, so nothing else has to be installed.
Account
No sign-up, no login, no connection. It only writes small settings files on your own PC.
Undoing changes
From the Changes tab. Machine-level undos ask for the Windows permission prompt again.
Not Microsoft
An independent project. Not created by, affiliated with, or endorsed by Microsoft. "Windows" is a trademark of Microsoft Corporation.
