What it changes

Five places Windows gets in your way.

Every option explains itself before it runs, carries a risk label, and — where Windows allows it — can be switched straight back.

Clean — noise

Cut the ads, suggestions and background clutter.

  • Remove web results from Start search LOW
  • Turn off Windows Copilot MODERATE
  • Stop auto-installing suggested apps NEEDS ADMIN
  • Scan for temp files, startup items and optional apps

Customize — feel

Make the desktop behave the way you expect.

  • Classic right-click menu LOW
  • Left-align the taskbar · show file extensions LOW
  • Seconds in the clock · "End task" on the taskbar LOW
  • This PC and Recycle Bin back on the desktop LOW

Optimize — speed

Trim the things that cost you responsiveness.

  • Best-performance visual effects · Game Mode LOW
  • Remove the menu-open and startup-app delays LOW
  • Turn off Fast Startup · disable hibernation MODERATE
  • Power modes · startup manager · disable the telemetry service MODERATE

Privacy — data

Close the taps Windows leaves running.

  • Set diagnostic data to the minimum NEEDS ADMIN
  • Limit the advertising ID, activity history and cloud search LOW
  • Turn off online speech recognition and typing collection LOW
  • Deny camera, microphone and location to apps MODERATE

Tools — fix

The maintenance jobs you'd otherwise google.

  • Flush the DNS cache · restart Explorer LOW
  • Clear the Windows Update cache MODERATE
  • Create a system restore point MODERATE
  • Run SFC and DISM to repair Windows MODERATE

Safety

Nothing happens behind your back.

Ownly is built so that any single change can be found, understood, and taken back.

FIRST RUN

It reads you the terms

A full disclaimer you have to scroll through and accept before the app will open. Anything you do is on you — and it says so, in plain language.

EVERY CHANGE

Lands in the Changes list

User-level settings apply instantly. Machine-level ones ask for a Windows permission prompt. Both show up with a one-click Restore.

ALWAYS

The Activity log shows the command

Every action — and every undo — is written down with the exact registry write or command it ran, and whether it needed admin.

Before you install

The honest bits.

Works on
Windows 10 (build 1809 and later) and Windows 11, 64-bit (x64). Not for ARM or 32-bit.
Install
None. It's a single Ownly.exe — put it anywhere and double-click. Delete the file to remove it.
Size
About 470 MB. Large because it bundles its own copy of everything it needs, so nothing else has to be installed.
Account
No sign-up, no login, no connection required. It only writes small settings files on your own PC.
Undoing changes
From the Changes tab. Machine-level undos ask for the Windows permission prompt again.
